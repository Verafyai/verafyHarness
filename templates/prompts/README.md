# Template prompts

Each ASC template ships with a prompt. Paste it into any capable AI, answer its questions, and it writes the program, contract or policy for your case, then tells you how to check it with the harness. The same prompts are on each template's page at [asc.verafy.ai/templates](https://asc.verafy.ai/templates).
