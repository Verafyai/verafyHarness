# Verafy App Pilots

A Verafy App Pilot (VAP) is one application deployed on top of the protocol, with a named app, the decision the jury makes, why it pays, what gets measured, and a done condition. VIPs change the protocol. VAPs prove it in use: stage 2 of the [roadmap](../roadmap.md).

| Status | Meaning |
|---|---|
| Idea | Written down; nobody contacted yet. |
| Scoped | The app's team agreed on the decision, the evidence and the metric. |
| Building | Verafy is building it alongside the team. |
| Live | Running in production. |
| Closed | The result is published, whether it worked or not. |
