## Summary

A verified profile can show the covenant wallet, its policy hash and its release history, checked against the chain and the signer.

## The problem today

Paid token profiles show links and socials, not whether the creator can dump.

## What the jury decides

- None per profile: the badge reads on-chain state. The jury rulings it links are the covenant wallet's.

## Why it pays

- Makes money: a higher-priced verified profile.

These are described, not estimated: the pilot is how they get measured.

## What we measure

- Paid verified profiles
- Clicks through to the covenant

## Shape

An API that returns the covenant state for a mint.

## Done when

The badge live on DEX Screener for covenant tokens.

Then this VAP moves to Live, and to Closed when the result is published.
