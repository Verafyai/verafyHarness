## Summary

Raise proceeds sit in a policy wallet. Each release needs a jury ruling that the stated milestone was met, judged from the team's evidence, which is pinned by hash.

## The problem today

Raise proceeds can leave a project treasury before the work they paid for is delivered.

## What the jury decides

- Whether each milestone was met.

## Why it pays

- Keeps customers: investors see funds released only on delivery.
- Saves money: funds stop leaving before delivery.

These are described, not estimated: the pilot is how they get measured.

## What we measure

- Releases ruled
- Disputes and appeals
- Time from milestone claim to release

## Shape

Treasury template plus milestone judgment. Verafy writes the milestone policy with each project.

## Done when

Three raises with milestone treasuries, each through at least one release.

Then this VAP moves to Live, and to Closed when the result is published.
