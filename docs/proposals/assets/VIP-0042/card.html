Verafy/ working definition draft v0

What is an inference program?

A program whose logic is an intention, carried out by AI. The intent is fixed. The reasoning is not.
01 intent

Immutable

The intention is fixed when the program is written.

02 governance

Amendable

It may allow amendments, by rules set out in advance.

03 proof

Verifiable

A proof of which AI ruled, checkable after the fact.

04 evidence

Contextual

Fed factual data to reason over. Sources update, so rulings can shift over time.

05 logic

Interpretable

The exact logic is fuzzy and may vary each time it runs.

06 code

Generative

No fixed logic. New logic is generated as it is needed.

07 precedent

Cached

10,000 lines written for one intent are kept as precedent and regenerated as models improve.

08 action

Agentic

It can spawn agents and processes: web searches, tools, sub-tasks.
