## Summary

The plan in docs/testnet.md, phase by phase: three seed nodes and about ten invited harnesses sealing blocks over the network; then bonds, slashing, audits and challenges; then a devnet market settled by a jury; then open registration.

## Motivation

The local testnet runs a whole network on one machine. No network of independently run harnesses exists yet.

## Done when

Ten or more independent harnesses on five or more models seal blocks for a week, with every number published.
