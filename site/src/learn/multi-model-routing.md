# Multi-model routing

*Start every question at the cheapest tier that can answer it safely, and move up only on disagreement.*

Not every question needs a frontier jury. The router sends each atom up a ladder:

1. a fast screen, such as Jev;
2. a panel of small models from several model families;
3. a mid-size panel;
4. a frontier panel.

A unanimous panel stops. A split one moves up. The top tier rules by majority against the bar.

Guardrails:
- the contract's floor is never lowered;
- L2 never takes a screen's answer;
- stakes cap what a screen may settle;
- audits drawn from the block hash re-check settled answers at the top tier.

Modeled, with the illustrative shares 30/35/20/15: about 4.4 times cheaper than sending everything to a frontier jury.
